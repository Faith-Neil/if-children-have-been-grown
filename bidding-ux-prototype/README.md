# 智能投标系统 UX 原型

这是按照 `ui/ux.md` 做的一版静态可交互原型，重点验证 UX，而不是最终视觉设计或生产代码。

## 已实现

- 我的工作台：首页优先展示待办、临近截止、阻断问题、进行中项目
- 项目概览：完成度、技术/商务分册状态、风险
- 响应矩阵：筛选、搜索、风险详情 Drawer
- 章节树：状态、问题数量、负责人
- AI 智能编辑器三栏布局
- 段落来源 / 问题侧栏
- 知识库开关
- AI 选区操作与 3 条修改建议
- Diff 确认
- 确认后写入正文并模拟新版本
- 自动保存状态
- 编辑锁与强制接管演示
- 锁定内容跳转入口
- Toast / Modal / Drawer 的使用规范

## 运行

直接双击 `index.html` 即可。

也可以本地启动静态服务器：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 说明

- 当前数据全部为模拟数据。
- 当前主要用于确认信息架构、页面密度、编辑器布局和关键交互。
- 没有接真实 API、权限、AI 模型、文档解析或知识库。
- 下一步适合根据这版原型确定框架（React/Vue）后拆成真实页面和组件。
