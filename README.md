# if-children-have-been-grown

投标技术标智能撰写系统（技术响应文件生成）项目仓库。

## 文档结构（分类管理）

| 路径 | 说明 |
|---|---|
| docs/PRD.md | 前端产品需求文档：产品定位、信息架构、核心页面、编辑台、AI 助手、检查与导出等 |
| docs/ARCHITECTURE.md | 前端架构文档：模块拆分、路由、状态管理、编辑器架构、权限、性能与审计 |
| docs/ROADMAP.md | 前端开发路线图：按主流程、章节生成、编辑台、检查导出、资料库与协作能力分阶段推进 |
| ui/ux.md | UI / UX 规范：页面布局、编辑器、AI 交互、Diff、来源、问题、状态与移动端策略 |

## 当前前端文档范围

当前已整理的前端方案主要覆盖：

- 项目工作台与项目风险视图
- 招标文件与原文定位
- 响应矩阵与项目事实表
- 写作方案确认与章节生成进度
- 编辑台 / AI 对话助手 / AI 选区修改
- Diff 确认、自动保存、编辑锁、版本管理
- 检查中心、人工处理队列、分册检查、全文检查
- 技术标 / 商务标分别导出
- 企业资料库与写作能力中心
- 全局搜索、任务分派、评论批注、知识引用地图等补充建议


## 版本管理

- v0.3：升级 AI 智能编辑器，新增图片资产库 + 模型-知识库读写隔离
