## 本地命令（仓库根目录）

- 安装并启动：Windows `& .\backend\bid-core\Start-Demo.ps1 -Install`，打开 http://127.0.0.1:8710/。
- 后端全部测试：`python -m pytest tests/backend -q`（约 15 分钟）。
- MySQL 测试：设 `ICG_DATABASE_URL`、`ICG_REQUIRE_MYSQL=1`，先 `alembic -c backend/bid-core/alembic.ini upgrade head`，再 `python -m pytest tests/backend -m mysql -q`。
- 冒烟与在线接口：`cd backend/bid-core && python smoke_t06.py`；`python tests/backend/session_live_http.py`；`python tests/backend/qa_error_idempotency_live_http.py`。
- 接口契约：改了接口后 `python backend/bid-core/export_openapi.py`，再 `python backend/bid-core/export_openapi.py --check`。
- 前端：`cd frontend/web`，`pnpm lint`、`pnpm test`、`pnpm build`、`pnpm e2e`。

## 环境变量

- `ICG_SECRET_KEY`：模型密钥与附件扫描件的加密主密钥，必须有（Start-Demo.ps1 未设置时在 `backend/bid-core/data/` 生成本机密钥）。
- `ICG_BLOB_DIR`：文件存储目录；生产要放在持久化且有备份的存储上。
- `ICG_WATERMARK_FONT`：敏感附件水印用的中文字体文件；不设时自动找黑体、微软雅黑等，找不到时导出整批失败并写明原因。
- RAGFlow 地址与密钥：用户提供的 Cloudflare 隧道地址会变，不写进仓库；在本机用环境变量或公司 RAGFlow 配置页填写。

## 实测发现（RAGFlow OpenAI 兼容接口，2026-10-30）

- 限流或上游错误时仍回 HTTP 200：普通模式正文为“**ERROR**: …”，流式只回一个空的结束块；模型名不对回 `{"code":101,…}`。
- 请求里的 `model` 必须写 `model`（用对话助手绑定的模型）；页面显示配置名称。
- Gemini 经 RAGFlow 每块连发两次；GLM-4.7-flash 把思考过程写进正文；云端模型容易写分析和“替换效果展示”，用户内容末尾的输出要求能压住。
- Cloudflare 隧道约 100 秒超时（HTTP 524），长输出要用流式。
- Jiekou.AI 的 deepseek-v4-flash/pro 在 RAGFlow 里能选，但 Jiekou 返回“model not found”：RAGFlow 里登记的模型名与 Jiekou 不一致，需要用户在 RAGFlow 改正后再测。
