智能投标系统 · 高保真原型（v1.2）

合成数据 · 全部虚构
依据：PRD v1.8、数据字典 v1.9、技术方案 v1.4.2。设计规范见 ../design-spec-v1.2.md，前端交接见 ../frontend-handoff-v1.md；截图（1440×900，编辑台另有 1280 / 1680）见 ../screenshots/。
视觉基准（neil 指定，风格不大改）：04a 编辑台、02d 解析结果、03 响应矩阵、05 合规检查。
技术：React 18 UMD + antd 5.29 UMD（本地 vendor，可离线打开，无需构建；正式 antd 主版本按 ADR-0021 在 M0 定）；ProLayout 风格外壳为手写。所有页面共用 assets/tokens.css、assets/theme.js、assets/shell.js（含状态代码 → 颜色注册表 UI.STATUS）。
主示例项目：青禾示例金融 2026—2028 年数据库及中间件维保服务采购项目（敏感项目，强制本地模型）。
01工作台 + 顶栏
投标截止时间 3 天内置顶标红；顶栏站内提醒下拉、后台任务抽屉、全局搜索下拉（只搜名称、不跨公司）。
02新建项目 + 招标文件解析
原文 · 分类树 · 条目卡片；抽取后处理三个入口（冲突待选定 / 疑似遗漏 / 引用未解析）与“确认解析结果”前提。
03响应矩阵（含 SLA 矩阵、挂证据）
要求矩阵 / SLA 矩阵二级切换；行状态与风险提示按字典 4.16；“挂证据”抽屉取代原资料匹配页签。
04编辑台与对话助手
来源标记、变量、【待补】、R43；答案卡（系统直查 · 未经模型）与“插入为引用”差异视图；1280 / 1440 / 1680 三档布局。
05合规检查
分册 / 全文检查；R18 只显示段落相似度；R24 页数写“估算”；定位、放行、只重跑本规则。
06Word 导出
递交版只由项目负责人导出；内部稿高敏信息一律掩码（前 3 后 4）；导出状态含“排队”。
07企业资料库 / 知识库
资质与人员（掩码前 3 后 4）；方案片段；历史标书入库状态按 archive_parse_status / kb_sync_status 英文代码绑定（PRD 5.5.3）。
08管理后台与平台管理
模型登记（本地只备用本地）、对应表 21 类、心跳与两条校验、规则配置与兜底词表、部署与服务状态、界面品牌（带预览）。
09登录（Keycloak 主题）
统一错误提示、账号锁定、首次登录强制改密三种状态；品牌区读取界面品牌设置。
10字典配置（A-03）
平台级字典（厂商与产品、证书类别、行业、附件槽位、划型标准）只有平台管理员可改；公司级可扩展字典追加本公司项；已使用代码只能停用。
11站内提醒列表（G-02）
17 类提醒按 notification_type 绑定；类型 / 已读 / 项目 / 时间筛选；点击跳转并标已读；第一期无站外渠道。
12后台任务中心（G-03）
运行中 / 排队 / 失败 / 已完成；详情抽屉（步骤、服务、重试记录）；平台管理员脱敏视图（无项目名、文件名，不能重试或取消）。
PoC编辑器 PoC 交互设计稿（M0-W06-01）
段落键稳定、锁定块、变量原子性、差异视图四个演示点；画板在 ../editor-poc/（01～04 .html / .png），合成文本。交付说明见 ../delivery/M0-W06-01.md。
