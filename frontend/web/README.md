### 架构分层与角色体系（WP-2 / WP-3 / WP-6 现行实树）

前端代码（`src/`）已彻底消除平铺单体，收敛为 8 大业务域子目录（根目录仅保留 `main.tsx` 应用挂载入口）：
- `app/`：全局应用启动、登录（`LoginScreen.tsx`）、可信会话核验（`session-navigation.ts`）与离开保护（`leave-guard.ts`）。
- `shell/`：顶栏底座（`AppShell.tsx`）、面包屑（`Breadcrumb.tsx`）、路由权限守卫（`RouteGuard.tsx`）与动作指令（`Can.tsx`）。
- `project/`：投标项目工作流、项目列表、团队成员、招标文件与响应矩阵（`ProjectPages.tsx` 等）。
- `editor/`：章节编辑台、段落引用胶囊（`CiteCapsule.tsx`）、选区气泡（`SelectionBubble.tsx`）与协同冲突处理。
- `library/`：企业资料库、SLA 承诺模板、元数据表格与商业标签（`BusinessTags.tsx`）。
- `admin/`：企业管理、敏感字段掩码（`MaskedField.tsx`）、审计日志与合规规则。
- `status/`：状态缺省页（403/404/网络异常）、长任务进度条与 SSE 订阅。
- `shared/`：单一权威源角色定义（`roles.ts`，收敛 8 大标准角色）、字典常量（`codes.ts`）、底层 API 请求封装与样式令牌。

身份认证支持两种模式：演示模式下提供账号快捷切换与 `legacy-demo-compat` 会话兼容；生产模式（`VITE_DEMO=0`）仅展示 Access Token 凭据登录并走 `rbac-8roles` 标准授权。

本轮外壳改为 `@ant-design/pro-layout@7.22.7`。地址可直接打开、刷新和前进后退；编辑台有未保存文字时，离开、后退和关闭标签都会先确认。引入后、分包前的单脚本为 JS 1564.53 kB / gzip 486.19 kB。任务、ISSUE-009 和 ISSUE-014 为 in-review，见[复核记录](../../docs/testing/2026-10-12-prolayout-routes.md)。

请求层（APP-M2-T002，原签署为done；本次回归修复另见ISSUE-034）解析 `/api/v1` 的 `{code, message, details, traceId}` 和旧 `/api` 的 `{error, request_id}`，页面提示带上追踪号。同一次写入只使用一把 `Idempotency-Key`。只有 GET 和已经带键的写入，才会在网络错误、没有统一错误体的 502 和 503 上用同一把键再试，最多 3 次（含首次）。没有键的旧写入不自动重试；ISSUE-021 给这些接口补键后这条限制解除。带 `MODEL_UNAVAILABLE` 的502与 `SECRET_KEY_UNAVAILABLE` 的503不重试，立刻提示追踪号。失败响应也核对请求来源，旧账号错误不退出新会话。409、422、423、428 不自动重试。提交章节版本时，请求头和正文 `idempotency_key` 是同一把键。见[请求层记录](../../docs/testing/2026-10-12-request-layer.md)。

## 运行

需要 Node.js 24 与 pnpm。先在本目录运行 `pnpm install --frozen-lockfile`，然后运行 `pnpm build`；后端将 `dist` 作为根页面提供。开发时先启动后端 8710，再运行 `pnpm dev`，开发页面 5173 将 `/api` 转发到后台。登录凭证只保留当前页面，不写浏览器长期存储。

`package.json` 登记依赖与构建命令；`pnpm-lock.yaml` 固定依赖的实际版本；`tsconfig.json` 保证页面字段和代码经过类型检查。JSON 不允许注释，所以这些文件的作用在本说明登记。
