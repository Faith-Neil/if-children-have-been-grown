## 工单 0 根因与修复（2026-11-05 取证）

- 现象：上传 `.doc` 走 RAGFlow DeepDOC 报 `Tokenizer … Post "https://api.jiekou.ai/…/embeddin…"`。
- 根因：`alpha::icg-tender` 仍绑租户默认外网嵌入 `text-embedding-3-large@…@Jiekou.AI`；就地改嵌入还会触发 Infinity `q_1024_vec not found`。
- 修复：招标临时数据集强制对齐公司知识库配置的内网嵌入（如 `bge-m3:latest@qwen@OpenAI-API-Compatible`）；不一致则**删除重建**；失败文案可见且可重试；失败清 `remote_parse`。
- 冒烟：同项目真实 `.doc` → `parsed`，16 页，61 条条款；假服务单测 `test_tender_remote_parse.py` 13 passed。
