## 当前开发边界

具备开发本地演示链路的基础；需要接入的模型和数据库留接口，不提前绑定产品。FastAPI只是组织后台接口的Python工具；它提供的接口描述与测试方法按 [官方运行说明](https://fastapi.tiangolo.com/tutorial/first-steps/) 和 [官方测试说明](https://fastapi.tiangolo.com/tutorial/testing/)核对。

内存仓库用同一进程内的互斥事务防止部分写入；以后数据库实现必须保留事务、公司过滤、版本比较和幂等约束。幂等是“同一请求重试不会多生成一个版本”。编辑权用带过期时间的租约令牌校验，即“每次写入都要出示仍有效的编辑凭证”。正式多进程部署需要由数据库或共享存储实现这些保证，不能直接复制内存锁到生产。

演示账号登录没有密码和生产身份认证；演示模型不发起外部调用；草稿不进入Word，检查和输出只绑定已提交正文。保存草稿不会改变已提交检查，提交新版本会使旧检查和下载过期。基础检查只覆盖空正文及待补标记，不代表44条业务规则已实施。

## 正式一期后续

生产账号与权限管理、持久数据库和迁移、真实解析/模型、可恢复长任务、完整检查/证据依赖、分册定稿、客户模板及目标部署环境尚需独立实现和验收。敏感材料是否允许外部服务处理，在真正接入前确认。本地demo通过不关闭这些事项。

实际验证结果以 [BE-M0-T01交付](../delivery/BE-M0-T01.md) 为准；代码与接口字段变化时同时更新生成约定、测试和解释。
