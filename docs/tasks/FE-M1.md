# FE-M1 项目主流程

任务版本：0.1；治理版本：g1.0；登记日期：2026-10-09；本轮计划登记关联 ISSUE-003。

来源映射：ROADMAP Phase 1；发布 Milestone 1。这是前端任务里程碑，与全系统 M0～M8 使用独立编号。

里程碑验收：项目、招标文件、响应矩阵和项目事实有可追溯的实际接口闭环。

本文件含 7 张任务卡。估算是基线、组件及真实 API 已具备时的一次前端增量，不包括后端/模型开发、评审和等待时间；开工核对预计超过 4 小时应继续拆卡并更新依赖。候选路径是待实现位置，不代表当前存在。

每张卡完成时必须新增自己的 `docs/delivery/<TASK_ID>.md`，说明变更结果、实际文件、验证命令及结果、未实现项和限制。有代码修改时，同时创建独立 `docs/code/<TASK_ID>.md` 并在交付中链接，解释入口、调用顺序、数据/状态流、关键判断与异常、依赖及限制；无代码修改在交付中明确写“无”并说明文档目的。随后同步统一 Issue、任务看板、项目进度、PRD/ROADMAP/ARCHITECTURE 的影响核对和文档索引。相关文档无需修改时，交付中逐项记录所核对章节与理由。

只有任务专属交付文件存在、验收证据齐全且状态同步后才能标 `done`；本地已验收与已合入/已发布分别记录。待产出的路径使用代码文本，不创建虚假的交付链接。

任务总览与状态定义见 [前端任务看板](../TASK_BOARD.md)，复用模板见 [任务卡模板](../templates/task-card.md)。
