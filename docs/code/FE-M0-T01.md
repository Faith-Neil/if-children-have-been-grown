## 改动与入口

原型整体迁至 `prototypes/bidding-ux/`，HTML继续加载同目录的CSS与JS。`app.js` 的页面初始化读取正文编辑区、锁提示和相关按钮，再统一设置可编辑状态。业务原型仍为无构建的静态演示。

## 状态与调用顺序

`setEditorEditable(editable)` 同步正文 `contentEditable` 和生成、Diff、确认、撤销/重做等按钮的禁用状态；锁定时隐藏选区工具条。演示锁切换以及填写有效接管理由之后，都通过同一函数恢复状态。

AI生成、打开Diff、确认写入、撤销/重做的事件处理器调用 `ensureEditable()`。该函数以编辑区当前状态为准，拒绝只读时的操作。锁前已经打开的Diff，在确认时也重新检查，防止只靠按钮禁用被绕过。

确认通过后才修改选中演示段落、来源和模拟保存提示。真实选区与多个建议仍未完整绑定，版本提示仍为静态示例；本任务没有实现持久化、服务端锁、权限或真实审计。
