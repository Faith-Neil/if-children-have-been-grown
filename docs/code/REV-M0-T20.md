# REV-M0-T20代码解释

2026-10-12；ISSUE-032 / foundation-review-fix-1；[复核记录](../reviews/2026-10-12-foundation-review.md)，[交付](../delivery/REV-M0-T20.md)。不新增业务功能或接口。

`frontend/web/src/api.ts`在请求或下载最终失败时，将错误与发起时的会话放入私有WeakMap。`isRequestFailureCurrent`只回答是否仍属于当前会话，不能把令牌序列化到日志或页面。App的report、重新读取和失败后补救入口均先核验；当前401仍显示追踪号并清身份，旧401不会登出新账号。503缺密钥按冻结契约直接停止，瞬时错误仍按原标记重试。

`App.tsx`新增displayedPathRef保存真正已载入的页。地址可以先表示目标，只有页面成功切换才更新显示页。未保存提示、浏览器返回/前进按显示页判断；失败重试不因地址相同而静默丢文字。现有成功页、输入和历史条目不被失败假装替换。

`snippet_publication.py`由片段存储锁覆盖既有仓储单事务，回执查找、修改、登记在同一回调。失败时恢复独立存储的记录和审计；资料仍不放入DemoState。锁顺序为片段→仓储，当前调用链无反向持锁；独立复核通过。保障只限当前内存进程，未改变跨进程边界。

`database.py`的read标记不限内存2048条。旧快照清理带原created_at和fingerprint作为条件，另一进程换掉回执后不再误删除。新测试执行真实解析预检查和DELETE SQL；真实MySQL连接/并发另需对应环境验证。

新增实际闭包、传输、片段并发及数据库容量/删除回归；命令和验证限度见复核记录。OpenAPI和既定错误码、角色权限、业务流程保持，不手改生成契约。
