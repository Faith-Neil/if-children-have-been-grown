## 1. 背景与目标

代码侧 WP-1～WP-7 已收官：前端八域目录、后端 `backend/bid-core/icg/` 分包、`/api/v1` 与八角色/演示关闸、OpenAPI/CI 门禁。

多数**现行**入口/架构文档仍按整改前「扁平 src + 巨石 `icg_demo/database|workflow` + `/api/demo` 主路径 + 三演示角色」记述，且 `AGENTS.md`（已冻结八域）与 `docs/architecture/repository-layout.md`（仍写扁平当前骨架）**权威打架**。

**目标：** 让活文档与实树、OpenAPI、角色模型一致；历史 delivery 只加「快照」标记，不重抄整仓。

## 2. 不做

- 不改 PRD / 知识库字典 / UX 纯交互规范（除非仅加「实现目录见 layout」指针）
- 不借机改 TS/Python 业务逻辑（若发现 `RoleMode` 前后端枚举不一致，**只在文档里标明已知缺口**，或另开工单；本包默认不修代码）
- 不强制 `git commit` 策略以外的事：按仓库惯例提交；建议独立 commit，message 含 `docs(governance): DOC-SYNC-1 …`
