1. 偏离表仍以免模型、可追溯的确定性正文匹配为主干；只有落入“已针对……制定专项响应措施”的通用兜底条款进入 LLM 兜底池。
2. 兜底池按所属叶子章节分组，每章最多 1 次本地 Qwen 批量 JSON 调用，并发度沿用 `ICG_SECTION_CONCURRENCY`；调用关闭思考模式，不透传 `thinking_budget`。
3. Prompt 传入压缩后的本章正文、Global Fact Sheet 和本章兜底条款列表，区分技术/服务类与违约/赔偿/保密责任类响应。
4. 每条模型响应执行长度、第一人称、完整句、机械套话、负偏离、历史做法、外实体、服务类证据动作、责任类“完全接受并遵守”、未支撑绝对化承诺等门禁；失败只回落该单条确定性兜底，不阻断导出。
