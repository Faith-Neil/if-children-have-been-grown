# 后端demo接口约定

`demo-v1.json`是从实际FastAPI应用导出的OpenAPI，即“前端向后台发送什么、后台返回什么”的机器可读约定。JSON不能放普通文字注释，因此用途在这里说明；该文件不手工修改。

更新入口：在仓库根执行 `.venv\Scripts\python.exe backend\bid-core\export_openapi.py`。后端运行时也可读取 `/openapi.json`。

此约定只覆盖本地demo。演示登录、内存数据库、模型替身及单章基础检查，不代表生产登录、数据库或完整合规服务。业务与生产约定继续按ISSUE-005完善。
